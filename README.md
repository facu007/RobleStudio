# Roble Studio

Landing page desarrollada con Vite, Tailwind CSS y micro-interacciones en JavaScript vanilla.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Variables de entorno

Copia `.env.example` si necesitas conectar integraciones:

- `VITE_ASSISTANT_WEBHOOK_URL`
- `VITE_BOOKING_WEBHOOK_URL`
- `VITE_BOOKING_TIMEZONE`
- `VITE_BOOKING_TIMEZONE_LABEL`
